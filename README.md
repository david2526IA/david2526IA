## Criterio de ingeniería

- Cada proyecto incluye documentación, pruebas automatizadas y CI.
- Distingo claramente prototipos, herramientas de análisis y sistemas de producción.
- No presento como control industrial ni como seguridad funcional aquello que solo es una ayuda de software.
- Priorizo resultados reproducibles, límites explícitos y datos que se puedan auditar.
